# images/

Drop product and page photos in here. Suggested layout:

```
images/
├── hero.jpg
├── collections/   crystals.jpg, jewellery.jpg, packs.jpg, bestsellers.jpg
├── products/      one file per product id, e.g. rose-quartz-pendant.jpg
├── about/         studio.jpg, founder.jpg
└── instagram/     1.jpg … 6.jpg
```

See the root `README.md` ("Where to swap in real photos") for exact sizes and
how each placeholder is replaced.
